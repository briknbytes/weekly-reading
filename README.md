# 📚 Weekly Reading

Every week the [Brik & Bytes](https://briknbytes.io) community reads one thing together: a KEP, a paper, a postmortem, an article, an RFC or a talk.

## How it works

1. **Start of the week:** we share the pick in `#weekly-reading` on Discord and add it here.
2. **During the week:** read it whenever you like and drop your questions and thoughts in the Discord thread.
3. **Sunday:** we meet in the voice channel for 30 minutes or more (depending on the content) to talk it through.
4. **After:** we add the takeaways to the reading's file here.

If nothing was shared during the week, we pick something on the spot when we meet.
